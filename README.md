# Verilog RTL Design & Cadence ASIC Synthesis Portfolio

A collection of synthesizable digital logic blocks designed in **Verilog HDL**, verified via simulation in **Cadence Xcelium & SimVision**, and synthesized to a **45nm standard-cell library** using **Cadence Genus**.

## Industry EDA Flow
* **HDL Language:** Verilog (IEEE 1364)
* **Simulation & Verification:** Cadence Xcelium (`xrun`)
* **Waveform Debugging:** Cadence SimVision
* **Logic Synthesis:** Cadence Genus (45nm Generic PDK)
